# 当前目录为火山视窗SDK存放路径

> 更新时间 2026/05/23 16:45

- 使用流程
  - 申明 JadeView 类  如 Jade  |  JadeView
  - 在 `启动方法` 函数内使用申明的类 `Jade.初始化 ()` 函数  初始化前可手动订阅部分可拦截系统事件
  - 使用 `Jade.置IPC频道回调 (本对象, "ipcChannelMessageCallback")` 设置订阅IPC回调函数，内有模板  第一个参数固定为 `本对象` 第二个参数为函数的 `@输出名 = "函数名称"`  注意：回调事件必须属性 `@强制输出 = 真` 二者缺一不可
  - ```cpp
    <火山程序 类型 = "通常" 版本 = 1 />
    
    方法 "IPC频道消息模板" <公开 类型 = 文本型
            注释 = "供 置IPC频道回调 匹配对象方法签名使用。参数依次为 通道名、窗口ID、请求数据。返回空文本表示不回传；返回非空文本时桥接层会自动调用 jade_text_create 并将 UTF-8 文本回给对端。" @强制输出 = 真
            @输出名 = "ipcChannelMessageTemplate">
    参数 通道名 <类型 = 文本型>
    参数 窗口ID <类型 = 整数>
    参数 数据 <类型 = 文本型>
    {
        // 通道名则是 注册IPC通道 时填写的文本
        返回 ("") // 注意：返回值直接为文本，内部会自动处理
    }

    ```
  - 设置完回调函数后进行订阅 如：`Jade.注册IPC通道 ("setTitlebarOverlayStyle")`
  - Jade.运行消息循环 ()
  - 在 申明变量处点击 JadeView > 点击闪电图标 > 选择 `应用就绪` 事件
  - 在应用就绪事件下面创建窗口
